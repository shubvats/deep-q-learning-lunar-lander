# Deep Q-Learning: Lunar Lander

## Overview
This project implements a Deep Q-Network (DQN) agent to solve the Lunar Lander environment using reinforcement learning.

The agent learns to land a spacecraft safely through repeated interactions with the environment.

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- OpenAI Gym
- Jupyter Notebook

## Concepts Implemented
- Deep Q-Learning
- Neural Networks
- Experience Replay
- Target Q-Network
- Bellman Equation
- Mean Squared Error (MSE)
- Epsilon-Greedy Exploration

## Project Structure
- `Deep_Q_Learning_Lunar_Lander.ipynb` – Main implementation.

## Environment
LunarLander-v2

## Learning Objective
Train an agent to maximize cumulative rewards and land the lunar module safely.
